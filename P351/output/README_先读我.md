# P351 关键缺失补齐 r10（2026-10-20）

本轮只做离线修改、编译、仿真及打包；没有连接板卡、下发射频或烧录。
一级1430 MHz本振和后级健康反馈按要求暂不加入。未填写任何虚构功率/增益标定值。

## 已补齐

1. **PL硬联锁**：FCLK100域增加250 ms主循环心跳看门狗，PS每50 ms喂一次。
   ARM停滞、外参考失效、整机模式TFS LD掉锁时，关闭板载TX路径，并把外部七线DSA输出置为全0（现有低有效63 dB安全档）。
   心跳/LD恢复不会复发；需要撤销RF请求、解除ARM并重新“应用”。独立直发不强制依赖TFS。
   新能力位使PS拒绝旧BIT；没有增加板外引脚，也没有更改厂家电平约束。
   这是独立于CPU指令执行的保护，不是独立供电/独立晶振保护；PS FCLK失效仍超出覆盖范围。
2. **STOP优先**：同一轮STOP或PL故障，取消先前排队的PC/屏幕APPLY，禁止循环尾部再次开启。
3. **屏幕精确码率**：480×272 v10，100000～20000000 bit/s，输入步进1 bit/s；功率仍0.5 dB。
   v6/op14分开传整数kbit/s及bit/s余数；CRC和独立STOP保持，旧v5/op13继续兼容。
   1 bit/s指设置分辨率；实际码钟受NCO量化与参考时钟误差影响，不等于绝对频率误差保证。
   保留四逻辑页、同步字16～33 bit、PN11/组帧、断屏6秒或重启停发和差分防闪。
4. **PC整机测试**：新增独立“整机最终RF测试”页，与屏幕共用PS原子事务及完整状态回读。
   同端点/请求号重传不会重复启动，旧固件不支持时明确拒绝，不降级成AD9361直发。
   原AD9361独立调试页仍为70～6000 MHz、0～89.75 dB；不使用功放增益模型、不锁死70 MHz。
5. **配套交付**：更新当前Vivado BIT、3份Vitis XSA和3份下载BIT；Vitis Debug ELF与独立严格构建逐段一致。
   同包包含原生TFT、可免装Python运行的Windows UI及正式保护BOOT，旧包保留。

## 离线证据

- 新BIT：WNS +0.233 ns、WHS +0.044 ns、WPWS +0.264 ns，失败端点0；仍有原有流水线/存储器等DRC警告，不宣称零警告。
- PL联锁XSIM：47项；完整板级GPIO实现模型：28项，覆盖能力位缺失、权限、喂狗、ARM、LD策略与回读失败。
- 新协议/控制器：103项；完整以太网解析、CRC破坏和重发：1022项。
- 屏幕：9832项离线检查、897组参数；1035项渲染检查/480次画面切换。
- HMI→真实UART解析→PS事务→回读→TFS RTL：1033次应用、64次STOP、11次草稿拒绝；18组SPI/DSA引脚重放。
- PC现有SPI/衰减链路：496项、399报文、27组RTL重放；实际芯片MISO/LD由模型提供。
- 两种PS构建均17个C文件通过ARM `-Wall -Werror`。原生屏幕0错误、1个原有隐藏p0/p1重叠警告。

这些是数字逻辑与软件证据，不是射频功率、杂散、解调或长期稳定性实测。

## 工程及使用

- Vivado：`vivado/P351_AD9361TX/P351_AD9361TX.xpr`，实现文件在其`.runs/impl_1/p351_top.bit`及`.ltx`。
- Vitis：`vitis_offline/P351_APP`，`Debug/P351_APP.elf`为明确人工RF联调版；Release不继承该权限。
- PS源码：`ps/src`，已同步`vitis_offline/P351_APP/src`。
- 屏幕：`screen/final_rf_v10_20261020/P351_FinalRF_480x272_v10.HMI`及同名`.tft`。
- UI源码：`ui/run_p351_ui.py`。新版页与原独立调试参数分离，不自动启动发射。
- 配套包：`output/P351_关键补齐_r10_20261020`及同名ZIP。

新PS必须配新BIT：只RUN新ELF而没有下载新平台BIT，将报告`missing hardware watchdog`并禁止发射。
在Vitis刷新工程后，用配套平台Program FPGA，再RUN对应ELF；不要沿用旧启动配置中的BIT。
人工联调ELF的权限只用于明确的人工作业，**不代表整机射频验收**。

包内`firmware/protected/BOOT.BIN`是正式保护候选：自动发射0、RF资格0、标定表为空。
因此未验收/未标定时拒绝发射是预期行为。它不是“上电即发”镜像，也不是人工联调ELF的Flash版本。
`firmware/manual/P351_APP.elf`须配同包`firmware/system.bit`，默认89.75 dB，无自动发射；负载/仪器仍须实体保护。
UI免安装版解压后运行`ui/P351_Control_r10/P351_Control_r10.exe`，必须保留旁边`_internal`整个目录。

## 尚不能离线消除的缺口

- TRX2及全链功率标定；功放单独增益不能代替混频/滤波/线缆损耗后的净增益。
- 最终输出频率、B99、镜像/杂散、频率跳变瞬态、冷启动/长时间稳定性、独立接收机解调对数实测。
- ADF4002环路锁定时间、失锁行为、相噪/稳定度实测；10 MHz驯服不等于射频与100 MHz确定相位一致。
- 按用户要求暂缓的一级本振及后级健康反馈。

上述硬件验收未做之前，不把“RF ON数字状态”标成“已测得射频”，不自动解除保护。
