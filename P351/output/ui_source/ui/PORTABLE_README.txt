AD9361TX UI 便携版（Windows 10/11，64 位）

1. 将 AD9361TX_UI_Windows_x64.zip 完整解压到普通可写目录；不要只复制 EXE。
2. 双击 AD9361TX_UI\AD9361TX_UI.exe。目标电脑无需安装 Python。
3. 板卡地址固定为 192.168.10.2。软件启动时读取本机到板卡的路由源地址；
   若未获取，先给有线网卡配置可到达板卡的地址（直连可用 192.168.10.100/24），
   再点“刷新本机 IP”。本机不限定必须是 .100，且不能与板卡地址相同。
4. 首次使用若 Windows 防火墙询问，请允许专用网络的 UDP 通信。
   控制端口为 UDP 40000，TX DAC 监视回传使用 UDP 40001。
5. 点击“测试”确认板卡有回应，再配置和发射。界面显示成功不替代射频实测。
6. 新UI打开后自动只读查询板卡当前配置（需要支持CFGQ的新版ELF）。
   收到匹配应答后才同步界面；未连接/旧固件会标为“未读到”。读取不启动或停止发射，
   不改变参考时钟、采集目的地址，也不会覆盖正在编辑的参数。
   可点击“读取板卡配置”重新查询。功率仅按校准基准和衰减估算，不是RF实测值。

可在命令行执行 AD9361TX_UI.exe --self-test 检查图形与协议组件；成功时会在
EXE 同目录生成 portable_self_test.ok。启动异常时检查同目录 ui_startup_error.log。

本压缩包只包含上位机 UI，不包含板卡固件、测试 BIT 数据或 Vivado ILA 探针。
目标电脑还需正确配置网卡、防火墙和显示缩放；本程序未签名，请核对包来源及
SHA256SUMS.txt 后使用。
